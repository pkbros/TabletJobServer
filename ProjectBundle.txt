    BREAKS. Symptoms: urllib/any-getaddrinfo dies with "[Errno 7] No address associated with

    a REAL unattended recovery has never been observed, so "it self-heals" was agent
    overclaim and got corrected by the owner. Leading hypothesis: the hotspot PHONE goes to
    sleep (its DNS/data path dies until it is woken); orientation is observation-correlated
    because the phone is awake when the household is awake. NOT YET DISPROVEN.
    Key unanswered question: during a flare, is ONLY DNS dead while the raw data path (HTTPS
    to a literal IP like https://1.1.1.1/) still works? If yes -> pure DNS bypass (DoH via
    IP-pinned 1.1.1.1 inside Python) would fix scraper+bot completely. If no -> nothing on
    the tablet helps and the fix is upstream (hotspot settings / keep-awake / home LAN return).
    The tablet MUTE is structural: a tablet with dead net cannot message ANYONE — so warning
    must come from OFF-TABLET (e.g., free Cloudflare uptime monitor on https://home.mind2.xyz,
    which exists on the tablet's tunnel and would die with the tablet) — not yet set up.

P2. LINKED-IN GUEST ENDPOINT THROTTLE WAVES + ANTI-BOT CHALLENGE WALLS.
    Endpoint: https://www.linkedin.com/jobs-guest/jobs/api/seeMoreJobPostings/search
    (guest, cookies.txt jar persists an aged anonymous session).
    History: Oct-14 8h cooldown after our own aggressive testing; Oct-17 daytime wave 309/330
    crawls 429'd (~94%, the SAME polite 2/min pace that worked cleanly Oct-18 morning);
    anti-bot JS challenge pages (obfuscated `_0x...` set-cookie logic) sometimes REPLACE the
    JSON while HTTP is 200-or-429. We cannot execute the JS (stdlib client), so a challenge
    wave cannot be "solved" — only waited out; guest quotas per address are unpublished and
    the egress identity ROTATES (Jio CGNAT), so pool heat from thousands of other phone users
    lands on every address weipment gets.
    The system currently: rate-caps.pace at <=2 req/min incl. details, skips a pair for the
    rest of its window on 429/challenge, and classifies alarm causes honestly.
    Owner has deferred any IP-shedding experiments until later.

P3. GROQ FREE-TIER TOKENS-PER-MINUTE BUCKET (this model tier: ~8,000 tokens/min,
    1,000 req/min): the digest judge call originally shipped a batch sized >8k tokens ->
    "HTTP Error 429: Too Many Requests" from api.groq.com (NOT LinkedIn) and the fallback
    shipped links-unjudged. MITIGATED by batching the judge to 6 jobs x 500-char desc
    (~4.8k chars ≈ 1.2k tokens incl. the ~1.5k-char system prompt) — verified working.
    Remaining ceiling: judge covers only 6 postings/window; a 7th new posting in a window
    ships as links-only, unjudged. Model is "qwen/qwen3.8-27b" (odd name — verify it exists
    on Groq's current model list / consider llama-3.1-8b-instant for higher limits).

P4. COVERAGE-HOLE MODEL (design tradeoff made on purpose, but document it):
    fetch window f_TPR=r3600 (last HOUR only), pairs swept once per 30-min window, dedupe
    TTL 1h. Each posting therefore gets ~2 collection chances (appears in two consecutive
    windows). If BOTH chances die (DNS flap or 429 wave), the posting is MISSING FOREVER
    (it slides out of the 1-hour fetch window) unless LinkedIn still shows it later or it
    resurfaces via another search pair. Under long flaps this loses real postings silently
    (the alarm digits "2 windows zero" catch total starvation, not per-pair misses).

P5. SINGLE DELIVERY CHANNEL + SILENT MESSAGE LOSS BUG (identified during bundle review):
    bot.py flush_alerts() reads each spool file, tries to send to recipients, logs
    "alert fail" on error — and then os.remove(p) runs UNCONDITIONALLY. During the Oct-18
    03:54-05:30 outage, any digest spooled then was READ, its sends FAILED, and the file was
    DELETED = message destroyed (did not queue for retry). This explains the empty spool
    despite undelivered digests. Need: delete only when at least one recipient actually
    received it (or retry-strategy cap), + a poison-file counter to avoid infinite loops.

P6. LEGACY/V2 MODE OVERLAP (complexity the owner explicitly dislikes):
    scraper.py has THREE modes (--collect, --digest, default burst legacy for Telegram
    "run-now" + --test). Default burst mode still does its own 30-min-era logic including
    its own alarm path, and bot.py "run-now" kills the v2 loop and restarts it (restart_loop
    pkill pair). Review whether default mode can be slimmed to reuse --collect/--digest,
    or run-now can just trigger the next window boundary instead of full restart.

P7. BOT = single point of failure for ALL notifications (no second alert channel), AND the
    bot's poll-loop has no watchdog (a hung/offline state is invisible until the owner
    notices silence). Also gotcha: some API edge 403s Python default UA on outbound calls —
    every outbound HTTP must send a browser UA header.

P8. relative quality gaps (small, tracked):
    - digest shows jobs with empty desc fields when detail trickle couldn't finish (cap 6);
    - judge failure ships links (by design) but those rows are marked sent -> never re-judged;
    - preskipped-senior rows counted but not surfaced beyond a count line;
    - compose_searches halves logic (legacy) coexists with all_pairs sweep (v2) — two composers.

P9. INFRA: tablet is OFF the home LAN (hotspot only), ssh mind2 (LAN .50) times out; PC
    reaches it only via `ssh mind2remote` tunnel; if hotspot dies, agent loses access AND the
    owner loses Telegram delivery simultaneously. RAM ceiling ~900MB with ~235MB already eaten
    by Google-less LineageOS background services + our ~90MB total; anything that adds
    processes/memory must justify itself.

P10. AGENT GOTCHAS that keep biting (so future agents don't rediscover):
    - PowerShell double-quotes EXPAND $(...) and $var and mangle nested quotes passing
      through ssh — always write a .sh/.py locally, scp it, execute it (repeatedly violated,
      repeatedly punished).
    - PowerShell ">" writes UTF-16; use [IO.File]::WriteAllText/ReadAllText with UTF8 —
      default Get-Content also mis-decodes and double-mangles UTF-8 (mojibake like "â€”").
    - pkill -f '<name>' inside an ssh one-liner kills the session running it (use bracket
      patterns, kill by exact PID instead; boot scripts must never contain pkill).
    - SQLite note: "desc" is a RESERVED word — always quote as "desc".
    - Groq/LinkedIn some edges 403 the python default User-Agent — always set browser UA.

#!/data/data/com.termux/files/usr/bin/python
"""job scrapper v2: paced collector + 30-min digest builder (anti-throttle redesign 2026-10-17).
Modes:
  python scraper.py --collect   gather <=2 queries from due-queue into store (safe for 1-min ticks)
  python scraper.py --digest    judge this window's new rows (1 Groq call), spool digest, mark sent
  python scraper.py             legacy full burst run (manual / Telegram run-now) — unchanged UX
  python scraper.py --test      1 query, raw print, no LLM, no spool
Reads ~/code/jobscrapper/config.json. GROQ_API_KEY from env.
Store: seen.db rows survive ~seen_ttl_hours (dedupe memory MUST outlive the 1-hour f_TPR window,
else overlapping windows re-collect and re-send the same postings); each digest only clears payloads.
"""

import http.cookiejar, random

BASE = os.path.join(HOME, "code", "jobscrapper")
UA = {"User-Agent": "Mozilla/5.0 (Linux; Android 10) AppleWebKit/537.36 Chrome/120 Mobile Safari/537.36"}

_OPENER = urllib.request.build_opener(urllib.request.HTTPCookieProcessor(_JAR))
SENIOR_RE = re.compile(r"\b(senior|sr\.?|lead|staff|principal|manager|director|\bhead\b|\bvp\b|chief|architect)\b", re.I)
CHALLENGE_RE = re.compile(r"_0x[a-f0-9]{6}|captcha|meta http-equiv=.refresh", re.I)


def is_challenge(html):
    return len(html) < 8000 and bool(CHALLENGE_RE.search(html))


def cfg():
    with open(os.path.join(BASE, "config.json")) as f:
        return json.load(f)


def db():
    os.makedirs(BASE, exist_ok=True)
    c = sqlite3.connect(os.path.join(BASE, "seen.db"))
    c.execute('CREATE TABLE IF NOT EXISTS seen(job_id TEXT PRIMARY KEY, first_seen REAL, sent_ts REAL, title TEXT, company TEXT, location TEXT, link TEXT, "desc" TEXT, preskip INTEGER DEFAULT 0)')
    for col in ("sent_ts", "title", "company", "location", "link", "preskip"):
        try:
            c.execute("ALTER TABLE seen ADD COLUMN %s" % col)
        except sqlite3.OperationalError:
            pass
    try:
        c.execute('ALTER TABLE seen ADD COLUMN "desc" TEXT')
    except sqlite3.OperationalError:
        pass
    # one-time migration: legacy rows (no title/preskip metadata) were already delivered by v1 runs
    c.execute("UPDATE seen SET sent_ts=first_seen WHERE sent_ts IS NULL AND preskip IS NULL AND title IS NULL")
    c.execute("CREATE TABLE IF NOT EXISTS crawls(ts REAL, kind TEXT, q TEXT, parses INTEGER, err TEXT)")
    return c


def fetch(url, params, tries=3):
    """network errors (DNS flap etc.) retried in-run; HTTPError surfaces to caller (caller sees 429)."""
    q = urllib.parse.urlencode(params)
    req = urllib.request.Request(url + "?" + q, headers=UA)
    err = None
    for attempt in range(tries):
        try:
            with _OPENER.open(req, timeout=25) as r:
                if attempt:
                    print("fetch ok on attempt %d" % (attempt + 1), flush=True)
                return r.read().decode("utf-8", "ignore")
        except urllib.error.HTTPError:
            raise
        except Exception as e:
            err = e
            if attempt < tries - 1:
                print("fetch retry %d/%d (%s)" % (attempt + 1, tries, str(e)[:100]), flush=True)
                time.sleep(5 if attempt == 0 else 15)
    raise err


def all_pairs(c):
    """every composed search pair (collector walks ALL pairs each window; no burst-halving needed)."""
    terms, locs = c.get("terms", []), c.get("locations", ["India"])
    pairs = []
    for g in [terms[i:i + 7] for i in range(0, len(terms), 7)]:
        q = "(" + " OR ".join('"%s"' % t for t in g) + ") AND (fresher OR intern OR junior) NOT senior NOT lead"
        for loc in locs:
            pairs.append({"keywords": q, "location": loc})
    return pairs


def compose_searches(c):
    """legacy alternating-halves composer for burst mode (unchanged)."""
    if c.get("searches"):
        return c["searches"]
    pairs = all_pairs(c)
    try:
        with open(os.path.join(BASE, "run_count")) as f:
            n = int(f.read().strip() or 0)
    except Exception:
        n = 0
    try:
        with open(os.path.join(BASE, "run_count"), "w") as f:
            f.write(str(n + 1))
    except Exception:
        pass
    half = (len(pairs) + 1) // 2
    return pairs[:half] if n % 2 == 0 else pairs[half:]


def parse_search(html):
    """defensive: IDs first (semantic), fields via fallback patterns."""
    ids = re.findall(r"urn:li:jobPosting:(\d+)", html)
    seen, out = set(), []
    for jid in ids:
        if jid in seen:
            continue
        seen.add(jid)
        out.append({"id": jid, "link": "https://www.linkedin.com/jobs/view/%s/" % jid})
    # attach titles/companies by proximity scan (best-effort, may be partial)
    titles = re.findall(r'base-search-card__title[^>]*>\s*(?:<[^>]+>)?\s*([^<]{2,120})', html)
    companies = []
    for pat in (r'base-search-card__subtitle[^>]*>\s*(?:<[^>]+>)?\s*([^<]{2,120})',
                r'job-search-card__subtitle[^>]*>\s*(?:<[^>]+>)?\s*([^<]{2,120})',
                r'artdeco-entity-lockup__subtitle[^>]*>\s*(?:<[^>]+>)?\s*([^<]{2,120})',
                r'search-card__subtitle[^>]*>\s*(?:<[^>]+>)?\s*([^<]{2,120})'):
        companies = re.findall(pat, html)
        if companies:
            break
    locs = re.findall(r'job-search-card__location[^>]*>\s*([^<]{2,120})', html)
    clean = lambda s: _html.unescape(re.sub(r"\s+", " ", s)).strip()
    for i, j in enumerate(out):
        if i < len(titles):
            j["title"] = clean(titles[i])
        if i < len(companies):
            j["company"] = clean(companies[i])
        if i < len(locs):
            j["location"] = clean(locs[i])
    return out


def fetch_detail(jid):
    try:
        html = fetch(DETAIL_URL % jid, {})
        if is_challenge(html):
            return "", "", "", ""
        m = re.search(r'job-details-jobs-unified-top-card__job-title[^>]*>\s*([^<]{2,150})', html)
        title = _html.unescape(m.group(1)).strip() if m else ""
        c = re.search(r'job-details-jobs-unified-top-card__company-name[^>]*>\s*([^<]{2,120})', html)
        company = _html.unescape(c.group(1)).strip() if c else ""
        txt = _html.unescape(re.sub(r"<[^>]+>", " ", html))
        txt = re.sub(r"\s+", " ", txt)
        money = re.findall(r"(?:₹|Rs\.?|INR)\s?[\d,]+(?:\s?-\s?(?:₹|Rs\.?|INR)?\s?[\d,]+)?(?:\s?/\s?(?:month|mo|year|annum))?|\d+(?:\.\d+)?\s?LPA|stipend[^.]{0,80}", txt, re.I)
        stip = "; ".join(dict.fromkeys(money))[:200]
        return title, company, stip, txt[:1500]
    except Exception as e:
        return "", "", "", "detail fetch failed: " + str(e)[:100]


def groq_judge(api_key, model, jobs):
    body = json.dumps({
        "model": model,
        "messages": [
            {"role": "system", "content": "You triage job postings for a FRESHER student (zero experience) seeking internships/entry-level/junior roles in full-stack, AI engineer, AI/ML, SDE in India (Noida/Delhi/Gurugram/Bangalore). For EACH posting decide TWO flags. SCAM first: scam=true for course sellers, training/placement/certification fees, 'pay to join', 'earn up to X'/vague stipends ('up to' without base), data-entry/typing/captcha work, Telegram-only applications with no company, multi-level/referral schemes. Genuine companies with real roles = scam=false even if imperfect. FIT second (only if not scam): fit=true ONLY for fresher/entry-level/0-1 year/intern postings; false for senior/lead/staff/principal or 2+ years. Reply ONLY a JSON list, one object per posting: [{\"id\":..., \"scam\": true/false, \"fit\": true/false, \"role\": \"<short title>\", \"company\": \"<name or 'not listed'>\", \"stipend\": \"<from posting or 'not listed'>\", \"location\": \"<city>\", \"reqs\": \"<top requirements, max 12 words>\", \"why\": \"<fit reason, max 8 words>\"}]. No prose, no markdown, JSON list only."},
            {"role": "user", "content": json.dumps(jobs)[:6000]}],
        "temperature": 0.2}).encode()  # 6k-char cap: judge batch must fit Groq's ~8k tokens/min bucket (2026-10-18)
    req = urllib.request.Request("https://api.groq.com/openai/v1/chat/completions", data=body,
                                 headers={"Authorization": "Bearer " + api_key,
                                          "Content-Type": "application/json",
                                          "User-Agent": "Mozilla/5.0 (Linux; Android 10) AppleWebKit/537.36 Chrome/120 Mobile Safari/537.36"})
    with urllib.request.urlopen(req, timeout=120) as r:
        content = json.loads(r.read().decode())["choices"][0]["message"]["content"]
    m = re.search(r"\[.*\]", content, re.S)
    return json.loads(m.group(0)) if m else {"raw": content[:2000]}


def ingest(con, jobs):
    """insert unseen rows with payloads; mark obvious-senior rows preskipped.
    returns (new_rows, kept_existing_n)."""
    new, kept = [], 0
    for j in jobs:
        row = con.execute("SELECT 1 FROM seen WHERE job_id=?", (j["id"],)).fetchone()
        if row:
            kept += 1
            continue
        title = j.get("title", "")
        preskip = 1 if title and SENIOR_RE.search(title) else 0
        con.execute("INSERT INTO seen VALUES (?,?,?,?,?,?,?,?,?)",
                    (j["id"], time.time(), time.time() if preskip else None,
                     title, j.get("company", ""), j.get("location", ""),
                     j.get("link", ""), "", preskip))
        if not preskip:
            new.append(j)
    con.commit()
    return new, kept

# ---------------- collector (<=2 requests per tick) ----------------

def collect(c):
    cadence = c.get("cadence_min", 30) * 60
    fights = 0  # fetches this tick
    details_used = count_detail_crawls(cadence)
    con = db()
    throttle = False
    # 1 search due (round-robin all pairs), then 1 detail (trickle) — total <=2
    spairs = [p for p in all_pairs(c) if not recent_crawl(con, "search|%s|%s" % (p["keywords"], p["location"]), cadence)]
    djobs = [(r[0], r[1]) for r in con.execute(
        "SELECT job_id FROM seen WHERE sent_ts IS NULL AND preskip=0 AND \"desc\"='' "
        "AND first_seen > ? ORDER BY first_seen DESC LIMIT 1", (time.time() - cadence,))]
    for plan in ("search", "detail"):
        if fights >= 2 or throttle:
            break
        if plan == "search":
            if not spairs:
                continue
            p = spairs[0]
            label = "search|%s|%s" % (p["keywords"], p["location"])
            try:
                html = fetch(SEARCH_URL, {"keywords": p["keywords"], "location": p["location"],
                                          "f_TPR": c["time_window"], "start": 0})
            except urllib.error.HTTPError as e:
                log_crawl(con, label, 0, "HTTP %s" % e.code)
                if e.code in (429, 999):
                    throttle = True
                continue
            except Exception as e:
                log_crawl(con, label, 0, str(e)[:120])
                continue
            if is_challenge(html):
                log_crawl(con, label, 0, "anti-bot challenge")
                throttle = True
                continue
            jobs = parse_search(html)
            new, kept = ingest(con, jobs)
            log_crawl(con, label, len(jobs), "")
            print("collect search: %d parsed, %d new, %d kept" % (len(jobs), len(new), kept), flush=True)
            fights += 1
        else:
            if details_used >= c.get("detail_cap", 6) or not djobs:
                continue
            jid = djobs[0][0]
            label = "detail|%s" % jid
            try:
                t, comp, stip, d = fetch_detail(jid)
            except urllib.error.HTTPError as e:
                log_crawl(con, label, 0, "HTTP %s" % e.code)
                if e.code in (429, 999):
                    throttle = True
                continue
            except Exception as e:
                log_crawl(con, label, 0, str(e)[:120])
                continue
            log_crawl(con, label, 1 if d else 0, "")
            up = {}
            if t:
                up["title"] = t
            if comp:
                up["company"] = comp
            if d:
                up["desc"] = d
            if stip:
                up["stipend_hint"] = stip
            if up:
                setr = ", ".join(('"%s"=?' % k) if k == "desc" else ("%s=?" % k) for k in up)
                con.execute("UPDATE seen SET %s WHERE job_id=?" % setr,
                            tuple(up.values()) + (jid,))
            if t and SENIOR_RE.search(t):
                con.execute("UPDATE seen SET preskip=1, sent_ts=? WHERE job_id=?", (time.time(), jid))
            con.commit()
            print("collect detail %s: %s" % (jid, "ok" if d else "no desc"), flush=True)
            fights += 1
        if fights < 2:
            time.sleep(random.uniform(c["request_gap_s"], c["request_gap_s"] + 8))
    con.execute("DELETE FROM crawls WHERE ts < ?", (time.time() - 2 * 86400,))
    con.commit()
    con.close()
    save_jar()
    return 75 if throttle else 0


def recent_crawl(con, kind, within):
    """exact-label matching; pairs repeat with identical kind strings → round-robin sweep."""
    return con.execute("SELECT 1 FROM crawls WHERE kind=? AND ts > ? LIMIT 1", (kind, time.time() - within)).fetchone()


def count_detail_crawls(within):
    con = db()
    n = con.execute("SELECT COUNT(*) FROM crawls WHERE kind LIKE 'detail|%' AND ts > ?",
                    (time.time() - within,)).fetchone()[0]
    con.close()
    return n


def log_crawl(con, kind, parses, err):
    con.execute("INSERT INTO crawls VALUES (?,?,?,?,?)", (time.time(), kind, "", parses, err))
    con.commit()


# ---------------- digest (window builder; runs at 30-min boundary) ----------------

def digest(c):
    cadence = c.get("cadence_min", 30) * 60
    last_f = os.path.join(BASE, "last_digest")
    try:
        with open(last_f) as f:
            last_digest = float(f.read().strip() or 0)
    except Exception:
        last_digest = 0.0
    now = time.time()
    if last_digest and now - last_digest < cadence - 150:
        return  # not time yet
    con = db()
    window = last_digest or (now - cadence)
    rows = [dict(zip(("id", "first_seen", "link", "title", "company", "location", "desc"),
                     (r[0], r[1], r[6], r[3], r[4], r[5], r[7]))) for r in con.execute(
        "SELECT job_id, first_seen, sent_ts, title, company, location, link, desc, preskip FROM seen "
        "WHERE sent_ts IS NULL AND preskip=0 ORDER BY first_seen DESC")]
    preskipped_n = con.execute("SELECT COUNT(*) FROM seen WHERE preskip=1 "
                               "AND first_seen > ?", (window,)).fetchone()[0]
    wc = con.execute("SELECT COALESCE(SUM(parses),0), MAX(COALESCE(err,'')) FROM crawls "
                     "WHERE kind LIKE 'search|%' AND ts > ?", (window,)).fetchone()
    parsed_total, last_crawl_err = wc[0], (wc[1] or "")
    blocked = any(e for (e,) in con.execute(
        "SELECT err FROM crawls WHERE ts > ? AND	err NOT IN ('')", (window,)).fetchall())

    streak_f = os.path.join(BASE, "zero_streak")
    try:
        with open(streak_f) as f:
            streak = int(f.read().strip() or 0)
    except Exception:
        streak = 0
    if parsed_total == 0:
        if blocked or last_crawl_err:
            cause = "collection paused: %s" % last_crawl_err
        else:
            cause = "pages fetched OK but parser found NOTHING — markup may have changed"
        streak += 1
    else:
        streak = 0
    with open(streak_f, "w") as f:
        f.write(str(streak))

    digest_msg = build_digest(con, c, rows, preskipped_n)
    if digest_msg is None:  # empty window
        if streak >= 2:
            try:
                with open(os.path.join(BASE, "last_alarm_ts")) as f:
                    last_alarm = float(f.read().strip() or 0)
            except Exception:
                last_alarm = 0.0
            if time.time() - last_alarm >= 7200:
                digest_msg = alarm_text(streak, cause)
                with open(os.path.join(BASE, "last_alarm_ts"), "w") as f:
                    f.write(str(time.time()))
            else:
                print("alarm suppressed (2h rate limit): streak %d, cause %s" % (streak, cause), flush=True)
                digest_msg = None  # stay silent, log only
        else:
            digest_msg = "jobs: nothing new this window (%d pages scanned)." % parsed_total
    if digest_msg:
        write_digest(digest_msg)
        con.execute("UPDATE seen SET sent_ts=? WHERE sent_ts IS NULL", (now,))  # message delivered
        con.commit()
    prune(con, c)
    con.close()
    if digest_msg:
        with open(last_f, "w") as f:
            f.write(str(now))
        print(digest_msg[:500], flush=True)
    save_jar()


def alarm_text(streak, cause):
    return ("ALARM: ZERO jobs parsed %d windows in a row. Cause: %s. "
            "(fetch/network = tablet DNS or WiFi flap; 429/challenge = LinkedIn throttle, wait it out; "
            "parser-zero-on-200 = markup may really have changed)" % (streak, cause))


def build_digest(con, c, rows, preskipped_n):
    if not rows:
        return None
    # legacy judge flow, verbatim behavior
    for j in rows:
        if not j.get("desc"):
            j["desc"] = ""
    # Groq TPM bucket (~8k tokens/min on this model tier): cap batch to 6 jobs x 500-char desc
    # (~4.8k chars ≈ 1.2k tokens/call incl. system prompt). Rows beyond 6 fall to the unjudged-links
    # line; stored descs stay full. Verified judge round-trip 2026-10-18: 1.1s, valid JSON list.
    judge_rows = []
    for j in rows[:6]:
        jj = dict(j)
        jj["desc"] = (j.get("desc") or "")[:500]
        judge_rows.append(jj)
    try:
        verdict = groq_judge(os.environ["GROQ_API_KEY"], c["llm"]["model"], judge_rows)
        items = verdict if isinstance(verdict, list) else verdict.get("raw", verdict)
        if isinstance(items, list):
            fits = [v for v in items if v.get("fit") and not v.get("scam")]
            genuine_other = [v for v in items if not v.get("fit") and not v.get("scam")]
            scams = [v for v in items if v.get("scam")]
            judged = set(str(v.get("id")) for v in items)
            orphans = [x for x in rows if x["id"] not in judged]

            def card(v):
                link = next((x["link"] for x in rows if x["id"] == str(v.get("id"))), "")
                return ("\n%(n)d. %(role)s\n   Company: %(company)s | Location: %(location)s\n"
                        "   Stipend: %(stipend)s\n   Needs: %(reqs)s\n   Why: %(why)s\n   %(link)s" % {
                            "n": card.i, "role": v.get("role", "?"), "company": v.get("company", "not listed"),
                            "location": v.get("location", "?"), "stipend": v.get("stipend", "not listed"),
                            "reqs": v.get("reqs", "-"), "why": v.get("why", ""), "link": link})

            if fits:
                flines = ["freshers FIT (%d of %d new):" % (len(fits), len(rows))]
                for i, v in enumerate(fits, 1):
                    card.i = i
                    flines.append(card(v))
            else:
                flines = ["jobs: %d new, none fresher-fit." % len(rows)]
            if genuine_other:
                flines.append("\nalso genuine (%d):" % len(genuine_other))
                for i, v in enumerate(genuine_other[:6], 1):
                    card.i = i
                    flines.append(card(v))
            flines.append("(%d scams filtered, %d skipped non-fit, %d pre-skipped senior titles, %d pending details)"
                          % (len(scams), len(items) - len(fits) - len(genuine_other), preskipped_n,
                             con.execute("SELECT COUNT(*) FROM seen WHERE sent_ts IS NULL AND preskip=0 AND \"desc\"=''").fetchone()[0]))
            if orphans:
                flines.append("(unjudged %d: %s)" % (len(orphans), ", ".join(x["link"] for x in orphans[:5])))
            return "\n".join(flines)[:3500]
        return str(items)[:1500]
    except Exception as e:
        return "jobs: %d new, judge failed (%s). Links: %s" % (
            len(rows), str(e)[:100], ", ".join(x["link"] for x in rows[:10]))


def write_digest(digest_msg):
    os.makedirs(SPOOL, exist_ok=True)
    with open(os.path.join(SPOOL, "jobs-%d.txt" % int(time.time())), "w") as f:
        f.write(digest_msg)
    with open(os.path.join(BASE, "latest.txt"), "w") as f:
        f.write(digest_msg)


def prune(con, c):
    con.execute("DELETE FROM seen WHERE first_seen < ?", (time.time() - c["seen_ttl_hours"] * 3600,))
    con.commit()

#!/data/data/com.termux/files/usr/bin/python
"""tablet gateway bot: single Telegram face for all local apps.
Routes: /status (builtin) /weather (local :8003) /files (local :8001)
        /id (report chat id, for lock-down) /help
Outbound: apps drop text files in ~/srv/alerts/ -> forwarded to OWNER.
Env: TBOT_TOKEN (required), TBOT_OWNER (chat id; empty = open, set = locked).
"""
import json, os, subprocess, time, urllib.request, urllib.parse

TOKEN = os.environ.get("TBOT_TOKEN", "")
OWNER = os.environ.get("TBOT_OWNER", "")
API = "https://api.telegram.org/bot" + TOKEN if TOKEN else ""
HOME = os.path.expanduser("~")
ALERTS = os.path.join(HOME, "srv", "alerts")


def api(method, **params):
    if "reply_markup" in params and isinstance(params["reply_markup"], dict):
        params["reply_markup"] = json.dumps(params["reply_markup"])
    data = urllib.parse.urlencode(params).encode()
    req = urllib.request.Request(API + "/" + method, data=data)
    with urllib.request.urlopen(req, timeout=60) as r:
        return json.loads(r.read().decode())


def send_long(chat, text):
    text = text or "(empty)"
    while len(text) > 3500:
        cut = text.rfind("\n\n", 0, 3500)
        if cut < 500:
            cut = text.rfind("\n", 0, 3500)
        if cut < 500:
            cut = 3500
        api("sendMessage", chat_id=chat, text=text[:cut])
        text = text[cut:].lstrip()
    api("sendMessage", chat_id=chat, text=text)

def read_latest():
    try:
        with open(os.path.join(HOME, "code", "jobscrapper", "latest.txt")) as f:
            return f.read()[:3500] or "(empty)"
    except Exception as e:
        return "no digest yet: " + str(e)[:120]


def http_get(url):
    try:
        with urllib.request.urlopen(url, timeout=20) as r:
            return r.read().decode()[:1500]
    except Exception as e:
        return "app offline: " + str(e)[:150]


def sh(cmd):
    try:
        p = subprocess.run(cmd.split(), capture_output=True, text=True, timeout=15)
        return (p.stdout or p.stderr or "(no output)")[:1500]
    except Exception as e:
        return "error: " + str(e)[:200]


JOBCFG = os.path.join(HOME, "code", "jobscrapper", "config.json")


def jobs_cmd(arg):
    try:
        with open(JOBCFG) as f:
            c = json.load(f)
    except Exception as e:
        return "jobs config missing: " + str(e)[:120]
    sub = (arg or "").strip()
    if not sub or sub == "help":
        return ("MENU", "job searches — pick one:",
                "typed: /jobs config | /jobs terms a, b | /jobs locs x, y | /jobs add term")
    if sub == "help":
        return ("/jobs show — list searches\n/jobs add <keywords> | <location> — add pair\n"
                "/jobs clear — empty the list\n/jobs run-now — trigger a scan")
    if sub == "show":
        latest = read_latest()
        if latest.startswith("no digest yet"):
            lines = ["no scan results yet — first digest lands after next run. watching:"]
            try:
                with open(JOBCFG) as f:
                    c = json.load(f)
                for s in c.get("searches", [])[:15]:
                    lines.append("- %s @ %s" % (s.get("keywords"), s.get("location")))
            except Exception:
                pass
            return "\n".join(lines)[:1500]
        return latest
    if sub == "config":
        try:
            with open(JOBCFG) as f:
                c = json.load(f)
            return ("terms (%d): %s\nlocations: %s\n(~%d composed searches)" % (
                len(c.get("terms", [])), ", ".join(c.get("terms", [])),
                ", ".join(c.get("locations", [])), len(c.get("terms", [])) // 7 * len(c.get("locations", [])) or len(c.get("locations", []))))
        except Exception as e:
            return "config error: " + str(e)[:120]
    if sub.startswith("terms "):
        items = [t.strip() for t in sub[6:].split(",") if t.strip()][:20]
        if not items:
            return "usage: /jobs terms ml intern, sde intern"
        try:
            with open(JOBCFG) as f:
                c = json.load(f)
            c["terms"] = items
            c.pop("searches", None)
            with open(JOBCFG, "w") as f:
                json.dump(c, f, indent=1)
            return "terms saved (%d). next runs use them." % len(items)
        except Exception as e:
            return "save failed: " + str(e)[:120]
    if sub.startswith("locs "):
        items = [t.strip() for t in sub[5:].split(",") if t.strip()][:8]
        if not items:
            return "usage: /jobs locs India, Noida, India"
        try:
            with open(JOBCFG) as f:
                c = json.load(f)
            c["locations"] = items
            c.pop("searches", None)
            with open(JOBCFG, "w") as f:
                json.dump(c, f, indent=1)
            return "locations saved (%d). next runs use them." % len(items)
        except Exception as e:
            return "save failed: " + str(e)[:120]
    if sub.startswith("add "):
        term = sub[4:].strip()
        if not term:
            return "usage: /jobs add prompt engineer"
        try:
            with open(JOBCFG) as f:
                c = json.load(f)
            terms = c.setdefault("terms", [])
            if term not in terms:
                terms.append(term)
            c.pop("searches", None)
            with open(JOBCFG, "w") as f:
                json.dump(c, f, indent=1)
            return "term added (%d total)." % len(terms)
        except Exception as e:
            return "save failed: " + str(e)[:120]
    if sub == "clear":
        return "clear disabled — edit terms/locs instead (/jobs terms … rewrites the list)."
    if sub == "run-now":
        restart_loop()
        return "fresh scan started + timer reset, digest in a few minutes."
    return "unknown /jobs command. /jobs help"


def handle(chat, text):
    parts = (text or "").strip().split(None, 1)
    cmd, arg = parts[0].lower() if parts else "", (parts[1] if len(parts) > 1 else "")
    if cmd == "/id":
        return "chat id: %s" % chat
    if OWNER and str(chat) != str(OWNER):
        return "not authorized."
    if cmd == "/id":
        return "chat id: %s" % chat
    if cmd in ("/start", "/help"):
        return ("/status — box health\n/jobs — job searches (help inside)\n"
                "/files — download shelf\n/id — show my chat id")
    if cmd == "/jobs":
        res = jobs_cmd(arg)
        if isinstance(res, tuple):
            return res
        return res
    if cmd == "/status":
        return ("uptime: " + sh("uptime") + "\nmem: " +
                sh("free").split("\n")[1] + "\ndisk: " + sh("df -h /data").split("\n")[1])
    if cmd == "/files":
        try:
            fs = sorted(os.listdir(os.path.join(HOME, "srv", "files")))
            return "files:\n" + ("\n".join(fs) if fs else "(empty)")
        except Exception as e:
            return "files error: " + str(e)[:150]
    return "unknown. /help"


def recipients():
    ids = []
    if OWNER:
        ids.append(str(OWNER))
    try:
        with open(os.path.join(HOME, "code", "telebot", "recipients.txt")) as f:
            ids += [l.strip() for l in f if l.strip()]
    except Exception:
        pass
    seen, out = set(), []
    for i in ids:
        if i not in seen:
            seen.add(i)
            out.append(i)
    return out


def flush_alerts():
    dests = recipients()
    if not dests:
        return
    os.makedirs(ALERTS, exist_ok=True)
    for name in sorted(os.listdir(ALERTS)):
        p = os.path.join(ALERTS, name)
        try:
            with open(p) as f:
                text = f.read()[:4000]
            for d in dests:
                try:
                    send_long(d, text)
                except Exception as e:
                    print("alert fail %s: %s" % (d, str(e)[:120]), flush=True)
            os.remove(p)
        except Exception as e:
            print("alert fail:", str(e)[:150], flush=True)


def on_callback(chat, data, cq_id):
    try:
        api("answerCallbackQuery", callback_query_id=cq_id)
    except Exception:
        pass
    if OWNER and str(chat) != str(OWNER):
        return
    if data == "jobs:show":
        send_long(chat, jobs_cmd("show"))
    elif data == "jobs:run":
        restart_loop()
        api("sendMessage", chat_id=chat, text="fresh scan started + timer reset, digest in a few minutes.")


def main():
    if not TOKEN:
        print("TBOT_TOKEN not set")
        return
    os.makedirs(ALERTS, exist_ok=True)
    offset, tick, fails = 0, 0, 0
    print("gateway polling...", flush=True)
    while True:
        try:
            u = api("getUpdates", offset=offset, timeout=25)
            fails = 0
            for upd in u.get("result", []):
                offset = upd["update_id"] + 1
                if "callback_query" in upd:
                    cq = upd["callback_query"]
                    on_callback(cq.get("message", {}).get("chat", {}).get("id"),
                                cq.get("data", ""), cq.get("id", ""))
                    continue
                msg = upd.get("message", {})
                chat = msg.get("chat", {}).get("id")
                if chat and "text" in msg:
                    try:
                        res = handle(chat, msg["text"])
                        if isinstance(res, tuple):
                            api("sendMessage", chat_id=chat, text=(res[1] + "\n" + res[2])[:3500],
                                reply_markup=JOB_MENU)
                        else:
                            send_long(chat, res)
                    except Exception as e:
                        print("send failed:", str(e)[:150], flush=True)
        except Exception as e:
            fails += 1
            wait = min(300, 5 * (2 ** min(fails, 6)))
            print("poll error (fail %d, retry in %ds): %s" % (fails, wait, str(e)[:150]), flush=True)
            time.sleep(wait)
        tick += 1
        if tick % 4 == 0:
            try:
                flush_alerts()
            except Exception as e:
                print("alerts error:", str(e)[:150], flush=True)


if __name__ == "__main__":
    main()
